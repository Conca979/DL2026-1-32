# Examination Requirement for Deep Learning Final Exam Projects 2026-2027

## 1. Required Submission

- **Project Report (PDF):** 10–15 pages, excluding References and Appendix.
- **GitHub Repository:** Complete source code for data preparation, training, evaluation, and inference/demo.
  - A complete `README.md` must provide installation instructions and steps for reproducing the main experimental results.
- **Dataset Information:** Dataset link and `DATA.md` are required.
  - A complete `DATA.md` must provide: official dataset URL, dataset version, data split, preprocessing procedure, and scripts required to reproduce the data used in the experiments.
  - If the group creates a new or processed dataset, a downloadable link should be provided.
- **Submission Details:** 
  - Submitted by the **Group Leader** via Google Classroom of the course.
  - **Deadline:** 8:00 AM, October 7th, 2026.

### Naming Conventions
- **Report:** `1_32_Report.pdf`
- **Repository:** `DL2026-1-32`

## 2. Examination Format

| Component | Duration | Main Focus |
| :--- | :--- | :--- |
| **Project Overview** | 3 minutes | - Prepare **4 slides** as follows:<br>&nbsp;&nbsp;• **Slide 1:** Problem & Research Question<br>&nbsp;&nbsp;• **Slide 2:** Method & Experiments<br>&nbsp;&nbsp;• **Slide 3:** Key Results<br>&nbsp;&nbsp;• **Slide 4:** Conclusion / Demo<br>- Each group chooses one member to present the project overview.<br>- **Strict time limit:** No more than 3 minutes allowed. All groups will be asked to stop after 3 minutes. |
| **Q/A Examination** | 12 minutes | - Examine the understanding of the quantity and quality of work.<br>- Questions may be directed by examiners to any team member for answering. |

## 3. Project Report Template
*Length: 10–15 pages, excluding References and Appendix.*

| Order | Component | Requirements |
| :---: | :--- | :--- |
| **1** | Abstract | 150–200 words |
| **2** | Introduction and Research Question | 0.5–1 page |
| **3** | Related Work | 0.5–1 page |
| **4** | Dataset and Data Preparation | Link to official dataset URL and version is required |
| **5** | Methods | - Baseline Method<br>- Main Method<br>- Comparison Strategy |
| **6** | Experimental Setup | - **Setup 1:** Baseline vs Main Model<br>- **Setup 2:** Main Research Experiment<br>- **Setup 3:** Analysis / Robustness / Ablation Experiment |
| **7** | Results and Discussion | Reporting results without interpretation is not sufficient |
| **8** | Error and Qualitative Analysis | - Report error cases<br>- Analyze the underlying reasons |
| **9** | Conclusion and Limitations | ~0.5 pages |
| **10** | References | Cite approximately 5–10 relevant references |
| **11** | Appendix | Member Contribution Table is required |
